# ReiPod screenshots / 界面截图

These are unretouched browser captures of ReiPod at application revision [`35095ef`](https://github.com/A-AsukA-A/ReiPod/commit/35095ef3ce451963619280505c8a0317216b7726), captured on 2026-10-28 in an isolated Microsoft Edge session at a 520 × 780 CSS-pixel viewport. Fonts and artwork were loaded before capture; playback was paused for the Now Playing image.

截图来自上述版本的实际网页界面，未经界面重绘；使用隔离的浏览器会话，没有真实账号、私人资料库或凭证。它们展示当前实现，不作为原机 UI 校准依据。

- `cover-flow.png`: album browser / 专辑浏览
