安装 ReiPod 音乐扩展

网易云／QQ 音乐需要扩展连接平台。本地音乐无需安装扩展。当前提供桌面 Chrome／Edge 开发者加载方式；iPhone 请使用 ReiPod App。

Mac：半自动安装

  1. 下载安装助手，保留文件名 install-reipod.command。
  2. 打开“终端”，输入 bash （末尾留一个空格），把下载的文件拖到终端，再按回车。脚本会下载、校验并解压扩展，打开安装文件夹和浏览器扩展管理页。
  3. 在扩展管理页开启“开发者模式”，点击“加载已解压的扩展”，选择助手打开的 MusicBridge 文件夹。
  4. 返回 ReiPod，刷新页面，再选择扫码登录。以后不要删除该文件夹；更新后在扩展管理页点击“重新加载”。
安装助手不会自动开启开发者模式、修改浏览器策略或替你确认安装。浏览器阻止脚本直接安装扩展，最后一步需由你完成。查看脚本。

Windows／手动安装

  1. 下载扩展 ZIP，解压到长期保留的文件夹。
  2. 在地址栏输入 edge://extensions/ 或 chrome://extensions/。
  3. 开启开发者模式，点击“加载已解压的扩展”，选择直接包含 manifest.json 的文件夹。
  4. 返回 ReiPod，刷新后重试登录。

扩展凭证仅保存在扩展本地存储；页面只持有独立会话标识。无需本机 HTTP 后端。实现与验证范围 · 返回 ReiPod
